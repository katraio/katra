# Katra Client

The Katra Client is the Vue and TypeScript web application for Katra.

Use the repository-root Docker Compose environment for normal development. To work on the client directly:

```sh
npm install
npm run dev
```

Run the client checks with:

```sh
npm run check
npm run build
npm run test:sites
```

The client expects a running Katra Server. Setup and configuration documentation is maintained at [katra.io/docs](https://katra.io/docs/).
